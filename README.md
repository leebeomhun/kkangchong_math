# 깡충 수학

만 5~6세용 더하기(@+2, @@+2 등) 놀이 PWA. 화면은 빌드 도구 없이 정적 파일로 동작하고, 기록 동기화는 Python 표준 라이브러리와 SQLite로 실행합니다.

```
index.html            앱 전체 (HTML + CSS + JS 한 파일)
sync.js               기기별 오프라인 기록 보관과 서버 동기화
locked.html           보호자 비밀번호 화면 (열쇠 없는 기기에 nginx가 대신 보여 줌)
manifest.webmanifest  홈 화면 설치 정보
sw.js                 오프라인 캐시 (수정 후 배포할 때 VERSION 올리기)
icons/                앱 아이콘
assets/stickers/      OpenAI 이미지 모델로 만든 보상 스티커 원본과 생성 프롬프트
server/               기록 저장 API와 systemd 서비스 정의 (웹으로 공개하지 않음)
tests/                저장 API 및 여러 브라우저 동기화 검증
```

## 사용 흐름

1. 처음 화면 → **놀이 시작**: 보호자가 정해 둔 문제로 바로 시작합니다. 아이가 보호자 설정 화면을 거치지 않습니다.
   - 놀이 도중 집 버튼을 누르면 "그만할까?"를 묻습니다. 그만두면 처음 화면 버튼이 **이어 하기 2/5**로 바뀌고, 같은 날 남은 문제부터 이어 합니다(이 기기에만 보관).
   - 아이가 두 명 이상이면 처음 화면 위쪽에서 누가 놀지 고릅니다.
2. **보호자 메뉴**: 처음 화면 톱니바퀴를 1.5초 길게 누르면 열립니다.
   - 오늘의 문제 → **문제 정하기**
   - 기록 저장 상태와 마지막 저장 시각, 오늘 기록, 푼 문제 그래프(7일·8주)
   - 잘하는 것 · 어려운 것: 최근 30일 동안 10을 넘어가는 문제와 안 넘어가는 문제, 더하는 수별, 놀이별로 한 번에 맞힌 비율. 5문제 이상 풀고 60% 미만이면 '어려워해요'로 표시
   - 다시 연습할 문제, 소리(목소리·말 빠르기·효과음, 목소리 들어 보기, 한국어 목소리가 없는 기기 안내), 아이 추가·이름 바꾸기, 기록 지우기
3. **오늘의 문제**(보호자 메뉴 → 문제 정하기)에서 두 가지 방법 중 하나를 고름
   - **범위로 정하기**
     - 앞의 수: 한 자리 1~9 / 10~19 / 두 자리 10~99, 또는 직접 입력(0~99)
     - 더하는 수: +1 ~ +5 (여러 개 선택 가능)
     - 10을 넘어가는 문제(18+2, 29+3): 섞어서 / 빼기 / 이것만
     - 문제 수: 1~30
     - 실제로 나올 문제 예시와 전체 문제 가짓수가 보임. 조건에 맞는 문제가 없으면 이유가 시작 버튼 바로 위에 나옴
   - **직접 만들기**
     - `11` + `2` [넣기]로 한 문제씩 넣음. Enter로 다음 칸으로 넘어가고, 더하는 수는 남아 있어서 +2 문제를 이어 쓰기 쉬움
     - "여러 개 한꺼번에 쓰기"에 `11+2, 12+3`처럼 붙여 넣기 (쉼표·줄바꿈 등 무엇으로 나눠도 됨)
     - 앞의 수 0~99, 더하는 수 1~9, 30개까지
     - 목록에서 ×로 하나씩 지우기, "모두 지우기"는 두 번 눌러야 지워짐
     - "다시 연습할 문제 넣기": 아이가 처음에 틀린 문제를 한 번에 목록에 넣음
     - 내는 순서: 쓴 순서대로 / 섞어서. 한 판에 목록의 문제를 한 번씩 모두 풂
   - 놀이 종류: 아래 7가지 중 고르기. 고른 놀이가 골고루 섞여 나오고, 같은 놀이가 연달아 나오지 않음
   - **이대로 시작하기** → 아이가 놀이
4. 한 판이 끝나면 이번 판에 받은 별과 "5문제 중 4문제를 한 번에 맞혔어요"를 보여 주고, 선물 상자 → 스티커. "한 판 더!"는 같은 설정으로 바로 시작합니다. "문제 바꾸기"는 보호자용이라 길게 눌러야 열립니다.

기록과 설정은 기기와 서버에 저장되어 다음에도 그대로 남습니다. 같은 보호자 비밀번호로 접속하는 기기들은 같은 기록을 공유하며, 아이를 추가하면 아이마다 별·스티커·기록·문제 설정을 따로 모읍니다.

## 보상 스티커

토끼·유니콘·동물 친구·꽃·디저트 등 기존 파스텔 그림 30종에, 사진 속 아이와 좋아하는 토끼인형을 참고한 그림 6종을 더해 총 36종을 선물 화면과 스티커북에서 보여 줍니다. 새 스티커는 안아주기, 브이, 함께 공부, 별 선물, 당근 선물, 응원 장면이며 `assets/stickers/photo-friends-v1/`에 개별 투명 PNG와 생성 프롬프트를 보관합니다. OpenAI 내장 이미지 생성 도구로 미리 만든 그림을 앱에 포함했으며, 놀이할 때 이미지 API를 호출하지 않습니다. 서비스 워커가 그림도 저장하므로 앱을 한 번 온라인으로 연 뒤에는 오프라인에서도 볼 수 있습니다.

첫 화면 토끼도 같은 사진의 인형을 참고한 `assets/characters/floral-bunny-v1.png`로 표시합니다. 놀이 속 토끼도 같은 인형을 바탕으로 각각 새로 생성한 그림으로 표시합니다. 징검다리와 힌트에서는 뛰는 모습, 풍선 놀이에서는 파란 풍선을 든 모습, 당근 놀이에서는 손을 벌리고 기다리는 모습입니다. 길게 늘어진 꽃무늬 귀와 큰 분홍색 코를 공통으로 살렸으며, `assets/characters/`에 투명 PNG와 전체 생성 프롬프트를 보관합니다.

기존 이모지 저장 키와 중복 개수를 그대로 사용하므로, 예전에 모은 스티커는 기록을 지우지 않고 새 그림으로 바뀝니다. 원본 파일은 `assets/stickers/pastel-friends-v1.png`, 생성에 사용한 전체 프롬프트는 같은 폴더의 `generation-prompt.txt`에 있습니다. 그림마다 간격이 조금 달라 `index.html`의 `STICKER_FRAMES`에 표시 영역을 지정했습니다. 원본을 바꿀 때는 이 좌표와 서비스 워커의 캐시 버전도 함께 갱신합니다.

## 학습 설계

| 놀이 | 단계 | 하는 일 |
|---|---|---|
| 징검다리 | 수직선 | 깡충이를 시작 수에 두고 "깡충!"을 b번 눌러 이어 세기. 더하는 수가 커서 돌이 작아지면 돌 크기를 지키고 깡충이를 따라 옆으로 움직임 |
| 사탕 상자 | 10의 묶음 | 보라 사탕을 눌러 빈칸에 넣으며 세기. 20을 넘으면 '열 개 묶음 + 낱개 상자'로 보여 줌 (57 = 묶음 5 + 낱개 7) |
| 물고기 잡기 | 그림과 수에서 이어 세기 | 통 안에 처음부터 있던 노란 물고기와 마릿수를 함께 표시. 한 자리 수는 한 마리씩, 두 자리 수는 작은 물고기 10마리(5×2)를 한 칸에 모으고 '10'을 붙인 묶음과 낱마리로 보여 줌. 헤엄치는 보라 물고기를 b마리 잡아 통 위에 쌓으며 통에 적힌 수에서 이어 셈. 다 잡으면 빈 바다는 접히고 통이 가운데로 옴. 답은 비눗방울 |
| 별 따라 로켓 | 수의 순서 | 흩어진 별 중 '다음 수'를 찾아 차례로 누르면 로켓이 날아가며 선을 그음. 로켓은 별 숫자를 가리지 않게 별 바깥 모서리에 섬. 사이사이 다른 수(시작 수-1, 답+1 등)가 섞여 있음. 틀린 별을 눌러도 벌점 없이 "다음은 20!"으로 알려 줌. 답은 행성 |
| 풍선 터뜨리기 | 식만 보고 | 맞는 풍선 터뜨리기. 틀리면 징검다리 힌트가 자동으로 나옴 |
| 두더지 잡기 | 식만 보고 | 숫자 팻말을 든 두더지 세 마리 중 정답을 콩! 틀리면 "16 › 17 › 18" 이어 세기 띠가 나옴 |
| 당근 주기 | 식만 보고 | 배고픈 깡충이에게 정답 당근을 끌어다(또는 눌러서) 주기. 끄는 동안 깡충이 둘레에 놓을 곳이 표시됨. 틀린 당근이면 고개를 젓고 당근이 제자리로 돌아감 |

- 오답 보기는 아이들이 실제로 자주 하는 실수로 만듦: 시작 수까지 세기(c-1), 하나 더 세기(c+1), 더하기를 잊기(a), 두 칸 어긋남(c±2), 받아올림을 잊기(18+2 → 10)
- 정답이 세 보기 중 가장 작은 수·가운데·가장 큰 수가 되는 경우를 고르게 섞음. 예전처럼 늘 c-1, c, c+1이면 정답이 91% 가운데여서 세지 않고 '가운데 수'만 골라도 맞았음 (지금은 약 36%)
- 두더지·당근은 틀렸을 때 나오는 이어 세기 띠 자리를 미리 잡아 두고, 세로 화면의 말풍선은 두 줄 높이로 고정해서 아이가 누르려는 순간 놀이가 위아래로 움직이지 않음
- 처음에 틀린 문제는 `missed`에 쌓여 다음 판에 40% 확률로 다시 나오고(범위로 정하기일 때), 한 번에 맞히면 빠짐
- 예전 버전(놀이 3가지)을 쓰던 기기는 처음 열 때 새 놀이 4가지가 자동으로 켜짐. 문제 정하기 화면에서 끌 수 있음
- 사탕 개수는 20까지 "열둘, 열셋"(우리말), 그 위로는 "오십팔, 오십구"로 셈

## 로컬 실행

```bash
cd ~/kkangchong-math
python3 -m http.server 8080
# http://localhost:8080
```

서비스 워커(오프라인, 설치)는 HTTPS 또는 localhost에서만 동작합니다. 같은 와이파이의 태블릿에서 `http://서버IP:8080`으로 열면 게임은 되지만 설치는 안 됩니다.

## 현재 배포: https://aiedu.codesearch.ai.kr

- nginx가 **이 폴더를 그대로** 서비스합니다. 설정 파일은 `/etc/nginx/sites-available/aiedu.codesearch.ai.kr`입니다.
- 기록 API `/api/sync`는 로그인 확인을 거친 뒤 `127.0.0.1:8871`의 `kkangchong-sync.service`로 연결합니다. nginx가 백엔드 전용 인증 헤더를 넣으며, 토큰은 웹 루트 밖의 `/home/ubuntu/.config/kkangchong-math/sync-token`과 root 전용 `/etc/nginx/kkangchong-sync-proxy.conf`에 있습니다.
- `/server/`, `/tests/`는 웹에서 열 수 없습니다. 데이터베이스도 웹 루트 밖에 보관합니다.
- 이 폴더의 파일을 고치면 바로 사이트에 반영됩니다. 이미 설치한 기기에도 반영하려면 `sw.js`의 `VERSION`을 꼭 올려 주세요.
- `index.html`, `sw.js`, `manifest`는 접속할 때마다 새 버전을 확인합니다. 아이콘은 7일 동안 캐시합니다.
- 예전 aiedu 주소(`/learn`, `/api/...` 등)나 없는 주소로 들어오면 처음 화면으로 보냅니다.
- 인증서는 기존 Let's Encrypt 인증서(`aiedu.codesearch.ai.kr`)를 그대로 쓰고, 자동 갱신됩니다.

### 보호자 비밀번호 잠금

- 처음 접속하는 기기에는 앱 대신 `locked.html`(비밀번호 화면)이 나옵니다.
- 비밀번호를 맞히면 서버가 그 기기에 열쇠(쿠키 `kk_access`)를 줍니다.
  - 자바스크립트로 읽을 수 없고, HTTPS로만 보내집니다.
  - 유효 기간은 400일이고, 접속할 때마다 연장됩니다.
- 확인은 nginx가 서버에서 하므로 화면 코드를 고쳐서 우회할 수 없습니다.
- 열쇠 없이 열리는 것은 설치 정보(`manifest.webmanifest`)와 `icons/`뿐입니다. 이름과 아이콘만 들어 있습니다.
- 비밀번호 시도는 IP당 1분에 10번까지입니다. 넘으면 "1분 뒤에 다시"가 나옵니다.
- 비밀번호는 접속 기록에 남지 않습니다. 이 사이트는 주소 뒤 `?...` 부분을 기록하지 않습니다.
- 홈 화면에 설치한 앱이 브라우저와 쿠키를 따로 쓰는 경우(iPad 등)에는 설치 후 처음 한 번 더 입력해야 할 수 있습니다.

비밀번호와 기기 열쇠는 `/etc/nginx/kkangchong-access.conf`에 있습니다. 이 파일은 root만 읽을 수 있습니다.

```bash
sudo grep '# 비밀번호' /etc/nginx/kkangchong-access.conf     # 비밀번호 보기
sudo nano /etc/nginx/kkangchong-access.conf                  # 바꾸기 (파일 맨 위 설명 참고)
sudo nginx -t && sudo systemctl reload nginx                 # 반영
```

- 비밀번호는 **영어 소문자와 숫자**만 씁니다. 화면에서 대문자로 넣어도 소문자로 바꿔서 확인하고, 하이픈(-)과 띄어쓰기는 빼고 비교합니다.
- 비밀번호를 바꿔도 이미 열린 기기는 계속 열려 있습니다.
- 모든 기기를 다시 잠그려면 "기기 열쇠" 값(두 곳)을 32자 이하의 새 값으로 바꾸세요. 33자 이상이면 nginx 설정 검사에서 오류가 납니다.

### 예전 aiedu(eduapp)로 되돌리기

## 다른 곳에 배포 (HTTPS 필요)

- **GitHub Pages**: 저장소에 이 폴더를 올리고 Settings → Pages에서 브랜치 지정. 가장 간단합니다.
- **Netlify / Cloudflare Pages**: 폴더를 드래그해서 올리면 끝.
- **이 서버(nginx)**: 폴더를 `root`로 지정하는 server 블록을 추가하고 Let's Encrypt 인증서를 붙입니다.

정적 호스팅만 사용하면 기기 내 저장과 오프라인 놀이는 동작하지만, 기기 간 동기화에는 별도의 `/api/sync` 서버와 인증 연결이 필요합니다.

## 저장

별, 스티커별 수집 개수, 끝낸 판, 날짜별 풀이 기록, 날짜별 유형 통계(10 넘김 여부·더하는 수·놀이별로 [푼 문제, 한 번에 맞힌 문제]), 다시 연습할 문제, 문제·소리 설정을 서버에 저장합니다. 계정을 추가로 만들 필요 없이 기존 보호자 비밀번호로 연 기기들이 같은 기록을 사용합니다.

- **아이 여러 명**: 보호자 메뉴 → 아이에서 추가합니다(최대 6명, 인터넷 연결 필요). 첫째 아이는 예전 기록(`profile` 표, 브라우저의 `kkangchong-math-v1`)을 그대로 쓰므로 옮기는 작업이 없습니다. 다른 아이는 서버의 `children` 표와 브라우저 키 뒤의 `@아이ID`로 따로 보관합니다. 새 아이는 추가할 때의 문제 설정을 이어받습니다. 아이를 지우면 그 아이의 기록만 지워지고, 첫째 아이는 지울 수 없습니다.
- **유형 통계**는 이 기능을 넣은 뒤에 푼 문제부터 모입니다. 그 전 기록에는 놀이 종류가 남아 있지 않습니다.
- 그만둔 판(이어 하기)은 서버로 보내지 않고 그 기기에만 하루 동안 보관합니다.

- 브라우저에는 기존 `kkangchong-math-v1` 기록과 오프라인 작업을 보관합니다. 서버에 저장이 확인된 작업만 대기 목록에서 지웁니다. 저장 응답을 받지 못해 다시 보내도 고유 작업 ID로 중복 집계를 막습니다.
- 서로 다른 기기의 새 학습은 서버 트랜잭션으로 누적합니다. 설정은 바뀐 항목만 보내므로 한 기기의 목소리 변경이 다른 기기의 문제 수 변경을 덮어쓰지 않습니다. 같은 설정 항목을 동시에 바꾸면 서버에 나중에 반영된 값이 적용됩니다. 진행 중인 한 판의 문제 범위는 시작할 때 정한 값을 유지합니다.
- 접속 중에는 약 15초마다 확인하고, 인터넷 재연결·앱으로 돌아오기 때 다시 확인합니다. 보호자 화면의 **지금 동기화**로 즉시 확인할 수도 있습니다.
- 예전에 쓰던 각 기기에서 새 버전을 한 번 열면 기존 기록을 가져옵니다. 예전 기록에는 작업 ID가 없으므로 별·끝낸 판·스티커별 개수·날짜별 통계는 큰 값을 남기고 스티커 종류를 합칩니다. 서로 독립된 옛 기록의 총합을 더하지 않습니다. 최초의 실제 기록 또는 사용자 설정을 가진 기기의 설정을 가져오고, 이후의 옛 기록 가져오기는 서버 설정을 덮어쓰지 않습니다.
- 이관 전 원본은 해당 기기 localStorage의 `kkangchong-before-sync-v1`에 보관합니다. 기록 지우기 또는 서버의 기록 초기화로 제외된 미전송 작업은 `kkangchong-sync-recovery-v1`에 최근 3회까지 보관합니다.
- 보호자 화면에서 **기록 지우기**를 확인하면 연결된 모든 기기의 학습 기록이 초기화됩니다. 설정은 유지합니다. 초기화 전에 만들어진 미전송 기록과 아직 이관하지 않은 옛 기록은 다시 합치지 않습니다.
- 브라우저 데이터를 지워도 이미 서버에 저장된 기록은 다시 접속하면 가져옵니다. 아직 서버에 보내지 못한 오프라인 기록은 브라우저 데이터를 지우면 사라질 수 있습니다.

서버 데이터: `/home/ubuntu/.local/share/kkangchong-math/progress.sqlite3` (WAL, 트랜잭션, 디스크 쓰기 확인). 서버 재시작과 앱 업데이트 후에도 유지합니다. 디렉터리는 소유자만 접근할 수 있고 API 응답은 캐시하지 않습니다.

```bash
sudo systemctl status kkangchong-sync.service
sudo journalctl -u kkangchong-sync.service -n 30 --no-pager
# 백엔드 코드를 바꿨을 때만 해당 서비스 재시작
sudo systemctl restart kkangchong-sync.service
```

백업할 때는 실행 중인 DB 파일만 복사하지 말고 SQLite 백업 기능을 사용합니다. 백업도 웹 루트 밖에 보관합니다.

```bash
python3 - <<'PY'
import sqlite3
from pathlib import Path
from datetime import datetime
folder = Path.home() / '.local/share/kkangchong-math'
source = sqlite3.connect(folder / 'progress.sqlite3')
target_path = folder / ('backup-' + datetime.now().strftime('%Y%m%d-%H%M%S') + '.sqlite3')
target = sqlite3.connect(target_path)
source.backup(target)
target.close()
source.close()
target_path.chmod(0o600)
print(target_path)
PY
```
