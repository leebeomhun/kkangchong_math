# 사진 속 토끼인형 캐릭터

`floral-bunny-v1.png`은 `assets/image/`에 사용자가 제공한 사진 속 토끼인형을 참고해 만든 첫 화면용 캐릭터입니다.

- 생성: 2026-11-05, OpenAI 내장 `image_gen` 도구
- 특징: 아이보리색 복슬복슬한 털, 길게 늘어진 꽃무늬 귀, 검은 구슬 눈, 큰 분홍색 삼각 코
- 배경: 투명 PNG
- 전체 생성 프롬프트: `generation-prompt.txt`
- 사용: `index.html`의 `#homeBunny`, `sw.js`에서 오프라인 사전 캐시

## 놀이별 캐릭터

| 파일 | 표시하는 곳 | 자세 |
|---|---|---|
| `floral-bunny-hop-v1.png` | 징검다리, 다른 놀이의 징검다리 힌트 | 오른쪽으로 깡충 뛰는 토끼 |
| `floral-bunny-balloon-v1.png` | 풍선 터뜨리기 | 파란 풍선을 든 토끼 |
| `floral-bunny-carrot-v1.png` | 당근 주기 | 손을 벌리고 당근을 기다리는 토끼 |

놀이용 그림도 사진과 첫 화면의 토끼 그림을 참고해 OpenAI 내장 `image_gen`으로 각각 새로 생성했습니다. 모든 파일은 1254×1254 RGBA 투명 PNG이며, 전체 프롬프트는 `gameplay-generation-prompts.txt`에 있습니다. 첫 화면용 프롬프트는 `generation-prompt.txt`입니다.

징검다리 위쪽 여백은 실제 캐릭터 높이를 사용합니다. 당근이 이동하는 입 위치는 새 그림에 맞춰 가로 51.5%, 세로 41%로 설정합니다. 점프·응원·먹기 동작은 캐릭터를 감싸는 요소에 적용하며, 서비스 워커가 네 그림 모두 사전 캐시합니다. 사진 원본은 수정하지 않습니다.
